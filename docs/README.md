# AetherLang Platform Documentation

AetherLang is being developed as a complete path from workload intent to verified heterogeneous physical execution.

## Core additions

- Hardware Knowledge Layer
- Versioned Target Registry
- Capability Analysis
- Explicit Target Selection
- Hardware-aware Code Generation
- Target Adapter Contract
- Device Orchestration
- Execution Receipts and Verification

## Key principle

The language stays hardware-independent while the compiler and runtime become hardware-aware through explicit, versioned target knowledge and verified adapters.
